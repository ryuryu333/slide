# 想定する聴衆/前提知識
- Nix を使ったことがない、名前だけ知っている方

- 純粋関数型言語や Nix の知識は問いません

# 聴衆が得られるもの
Nix がどのように再現性を確保しているのか、その背景で純粋関数型言語がどのような役割を果たしているのかを知ることができます。

# セッションの概要
Nix は高い再現性が特徴のパッケージマネージャーであり、純粋関数型言語である Nix 言語で設定を記述します。
Nix を初めて見る人にとっては、なぜ JSON や YAML ではなく純粋関数型言語を利用するのか不思議に思うかもしれません。

本セッションでは、最初に従来のパッケージ管理で起こりがちな問題を整理し、Nix が再現性をどのように確保しているのかを紹介します。
そのうえで、Nix におけるビルドの仕組みを通して Nix 言語の性質を見ていきます。

純粋関数型言語そのものを詳しく解説することが目的ではなく、Nix の背景にある関数型的な発想が、どのようにその特徴につながっているのかを紹介します。
